설치 후 포트 충돌 오류가 나면 어떻게 하나요?

최신 v1.0.3을 먼저 사용해 주세요. v1.0.2부터는 이미 실행 중인 창이 있을 때 새 창 대신 기존 창을 안전하게 다시 불러오도록 개선되었습니다. 이전 버전의 프로세스가 남아 있다면 작업 관리자에서 HwpLens 또는 Node.js 프로세스를 종료한 뒤 다시 실행해 보세요.

어떤 문서 형식을 지원하나요?

HWP 5.0 문서와 HWPX 문서를 지원합니다. 암호가 설정된 문서는 안전을 위해 데스크톱 한글 프로그램에서 직접 열어 주세요.

문서는 외부로 전송되나요?

HwpLens는 로컬 파일을 탐색하고 미리보기하는 데스크톱 앱입니다. 문서는 사용자의 PC 안에서 처리됩니다.
